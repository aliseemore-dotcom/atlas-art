# Черновики (не импортируются)

`facts_draft.csv` — короткие интересные факты, написанные своими словами по общеизвестным сведениям. Они **не проверены**: у них нет источника, поэтому `npm run db:seed` их не читает и в интерфейс они не попадают.

Как перенести факт в базу: проверить его по независимому открытому источнику (энциклопедия, сайт музея), добавить источник в `data/sources_seed.csv`, перенести строку в `data/facts_seed.csv` с `source_id`.

Правило: ни один факт, формулировка или подборка не копируется из книг и статей, на использование которых у проекта нет разрешения.
