# 05 — Проверки и Definition of Done

## MVP1 — обязательные сценарии
- На `/regions/russia` отображается реальная шкала от средневековья до наших дней, минимум 50 импортированных авторов.
- При диапазоне 1880–1890 отображаются жившие в это время художники, без ошибочного привязывания к началу эпохи.
- При выборе жанра «пейзаж» выдаются соответствующие художники без портретистов, у которых этот жанр не указан.
- Поиск «Шишкин» находит Ивана Шишкина. Поиск не зависит от регистра; нормализует ё/е.
- Клик на узел/полосу ведёт к карточке с датами, жанрами, направлениями, статусом проверки.
- Художник с `birthYear=null` или приблизительной датой не ломает шкалу.
- Группы и движения не изображаются как лица с годами рождения и смерти.
- Нет выдуманных отношений «учитель» / «ученик».
- Пустые результаты объяснимы и есть кнопка сброса фильтров.
- Ширина 360px, управление клавиатурой, экран без картинок работают.
- В консоли нет ошибок, typecheck/lint/tests проходят.

## Unit tests
- Пересечение интервалов, в том числе null/uncertain.
- Разбор и нормализация поисковых имён.
- Фильтр movement vs genre.
- Конвертация координаты года в X при разных zoom.
- Валидация импорта/ошибок.

## E2E tests
- Главная → Россия → найти художника → карточка → назад.
- Поставить диапазон → задать жанр → сбросить фильтры.
- На мобильном открыть альтернативный списковый режим.

## Release gate
Не использовать непроверенные данные как достоверные; не публиковать изображения без корректных прав/атрибуции. Отчёт по покрытию контента и известным пробелам при каждом релизе.
