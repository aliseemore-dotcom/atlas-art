# 04 — UX/UI и поведение визуализаций

## Визуальный язык
«Современный цифровой музей»: тёплый почти белый фон #F7F5F0, угольный текст #222222, приглушённый латунный акцент #A38A62, аккуратная типографика, отсутствие чрезмерных градиентов. Контент первичен. На карточках произведений соблюдай исходное соотношение сторон изображения.

## Страницы
1. **/**: название, краткий интро, регионы, вход в русскую ветвь.
2. **/regions/russia**: tabs [Хронология, Направления, Связи], диапазон веков, строка поиска, жанры/направления, кнопки +/-/сброс, легенда и список.
3. **/artists/[slug]**: фото или заглушка; имя и вариант, точность дат, теги направлений/жанров, биография, 3–5 произведений если данные есть, связи с доказательствами, современники (алгоритмически), источники.
4. **/movements/[slug]**: годы, признаки, основные мастера и связи с другими течениями.
5. **/artworks/[slug]** (MVP2): произведение, атрибуция, права, музей, анализ.

## Графика хронологии
- Ось X — линейная по календарным годам, слева прошлое, справа настоящее.
- Отдельная типографика веков и отметок отдельных десятилетий при приближении.
- Каждая полоса: life interval, индикатор active interval при наличии, подпись фамилии.
- Отсутствующий год рождения/смерти обозначать незамкнутым краем/неопределённостью вместо фиктивной даты.
- Группировка по художественным движениям либо по эпохам; один художник с множественной принадлежностью не должен дублироваться в списке без пояснения.
- Пересечение по году: `lifeStart <= selectedEnd && lifeEnd >= selectedStart` для точных известных дат; для частичных данных отдельная логика неопределённости.
- При выборе художника выделять его полосу и подтверждённые отношения; современников — в отдельном полупрозрачном слое.
- Для ранних веков сильное приближение не должно притворяться точными днями/годами, если известен только век.

## Дерево направлений
- Узлы = школы/движения, рёбра = подтверждённые идеи влияния/ответвления.
- Это DAG с возможностью нескольких родителей, **не** обязательное бинарное или строго иерархическое дерево.
- В обзорном режиме скрывать мелкие узлы по уровню; раскрытие по клику.

## Граф художников
- Различать `учитель → ученик`, `повлиял →`, `сотрудничество ↔`.
- Современники — не обычные рёбра влияния; при запросе показывать списком, иначе возникнет «волосатый клубок».
- Легенда, тултипы, открытие карточки, клавиатурная навигация и список как альтернативный вид.

## Mobile
На узком экране граф по умолчанию свёрнут в список с фильтрами; отдельная кнопка полноэкранного интерактивного просмотра. Все ключевые функции доступны без hover.

## UI states
Пустой регион, ничего не найдено, неизвестные даты, отсутствие изображения, данные требуют проверки, проблема загрузки, недоступные этапы MVP2/3 — для каждого понятное состояние без ошибок консоли.
